## 第一部分：项目总览与技术栈

### 1.1 项目目标
构建一个校园范围内的C2C二手物品交易平台，核心功能为用户注册登录、商品发布与浏览、在线聊天（轮询）、订单状态管理。**不涉及线上支付**，所有交易由买卖双方线下完成。

### 1.2 技术栈明细表

| 层级 | 技术选型 | 版本/说明 |
|------|---------|----------|
| **Android SDK** | Java | minSdk 23 (Android 6.0)，targetSdk 33 |
| **客户端架构** | MVP (Model-View-Presenter) | 纯Java实现 |
| **网络框架** | Retrofit 2 + OkHttp 3 | 同步/异步请求，日志拦截 |
| **图片加载** | Glide | 4.x 版本 |
| **本地存储** | SharedPreferences + SQLite | 用户偏好 + 数据缓存 |
| **服务端框架** | Spring Boot | 2.7.x |
| **ORM框架** | MyBatis | 3.5.x |
| **数据库** | MySQL | 5.7+ / 8.0 |
| **认证方案** | JWT (JSON Web Token) | 有效期7天 |
| **文件存储** | 服务器本地磁盘 | 通过Spring静态资源映射访问 |
| **API通信协议** | RESTful + JSON | UTF-8编码 |
| **API文档** | Swagger 3 (OpenAPI) | 可选，方便调试 |

### 3.3 JWT 工具类与拦截器

#### JwtUtil.java
```java
package com.campus.trade.utils;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.SignatureAlgorithm;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import java.util.Date;
import java.util.HashMap;
import java.util.Map;

@Component
public class JwtUtil {

    @Value("${app.jwt.secret}")
    private String secret;

    @Value("${app.jwt.expiration}")
    private Long expiration;

    public String generateToken(Integer userId, String email) {
        Map<String, Object> claims = new HashMap<>();
        claims.put("userId", userId);
        claims.put("email", email);
        Date now = new Date();
        Date expiryDate = new Date(now.getTime() + expiration);
        return Jwts.builder()
                .setClaims(claims)
                .setIssuedAt(now)
                .setExpiration(expiryDate)
                .signWith(SignatureAlgorithm.HS256, secret)
                .compact();
    }

    public Claims parseToken(String token) {
        return Jwts.parser().setSigningKey(secret).parseClaimsJws(token).getBody();
    }

    public boolean validateToken(String token) {
        try {
            parseToken(token);
            return true;
        } catch (Exception e) {
            return false;
        }
    }

    public Integer getUserIdFromToken(String token) {
        return (Integer) parseToken(token).get("userId");
    }
}
```

#### JwtInterceptor.java（拦截器自动校验Token）
```java
package com.campus.trade.config;

import com.campus.trade.utils.JwtUtil;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Component;
import org.springframework.web.servlet.HandlerInterceptor;

import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

@Component
public class JwtInterceptor implements HandlerInterceptor {

    @Autowired
    private JwtUtil jwtUtil;

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
        // OPTIONS请求直接放行
        if ("OPTIONS".equalsIgnoreCase(request.getMethod())) {
            return true;
        }
        String token = request.getHeader("Authorization");
        if (token != null && token.startsWith("Bearer ")) {
            token = token.substring(7);
            if (jwtUtil.validateToken(token)) {
                // 将userId存入请求属性，方便后续Controller获取
                Integer userId = jwtUtil.getUserIdFromToken(token);
                request.setAttribute("currentUserId", userId);
                return true;
            }
        }
        response.setStatus(401);
        response.setContentType("application/json;charset=UTF-8");
        try {
            response.getWriter().write("{\"code\":401,\"msg\":\"未登录或Token已过期\"}");
        } catch (Exception ignored) {}
        return false;
    }
}
```

> **注意**：需要在`WebMvcConfig`中注册拦截器，并排除登录、注册、图片访问等公开路径。

#### AuthController.java（认证接口）
```java
package com.campus.trade.controller;

import com.campus.trade.common.BaseResponse;
import com.campus.trade.dto.request.LoginRequest;
import com.campus.trade.dto.request.RegisterRequest;
import com.campus.trade.entity.User;
import com.campus.trade.service.IUserService;
import com.campus.trade.utils.JwtUtil;
import com.campus.trade.utils.PasswordUtil;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/v1/auth")
public class AuthController {

    @Autowired
    private IUserService userService;

    @Autowired
    private JwtUtil jwtUtil;

    @PostMapping("/register")
    public BaseResponse<String> register(@RequestBody RegisterRequest req) {
        // 1. 校验邮箱是否已存在
        if (userService.findByEmail(req.getEmail()) != null) {
            return BaseResponse.error("该邮箱已注册");
        }
        // 2. 生成盐和加密密码
        String salt = PasswordUtil.generateSalt();
        String passwordHash = PasswordUtil.encryptPassword(req.getPassword(), salt);
        // 3. 保存用户
        User user = new User();
        user.setEmail(req.getEmail());
        user.setPasswordHash(passwordHash);
        user.setSalt(salt);
        user.setNickname(req.getNickname() != null ? req.getNickname() : "校园用户");
        userService.save(user);
        return BaseResponse.success("注册成功");
    }

    @PostMapping("/login")
    public BaseResponse<String> login(@RequestBody LoginRequest req) {
        User user = userService.findByEmail(req.getEmail());
        if (user == null) {
            return BaseResponse.error("用户不存在");
        }
        String inputHash = PasswordUtil.encryptPassword(req.getPassword(), user.getSalt());
        if (!inputHash.equals(user.getPasswordHash())) {
            return BaseResponse.error("密码错误");
        }
        String token = jwtUtil.generateToken(user.getId(), user.getEmail());
        return BaseResponse.success(token);
    }
}
```

#### UploadController.java（图片上传）
```java
package com.campus.trade.controller;

import com.campus.trade.common.BaseResponse;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.web.bind.annotation.*;
import org.springframework.web.multipart.MultipartFile;

import java.io.File;
import java.util.UUID;

@RestController
@RequestMapping("/v1/upload")
public class UploadController {

    @Value("${app.file.upload-dir}")
    private String uploadDir;

    @Value("${app.file.access-url}")
    private String accessUrl;

    @PostMapping("/image")
    public BaseResponse<String> uploadImage(@RequestParam("file") MultipartFile file) {
        try {
            // 1. 校验文件类型
            String originalName = file.getOriginalFilename();
            if (originalName == null || !originalName.matches(".*\\.(jpg|jpeg|png|webp)$")) {
                return BaseResponse.error("仅支持jpg、jpeg、png、webp格式");
            }
            // 2. 生成唯一文件名
            String suffix = originalName.substring(originalName.lastIndexOf("."));
            String fileName = UUID.randomUUID().toString().replace("-", "") + suffix;
            // 3. 确保目录存在
            File dir = new File(uploadDir);
            if (!dir.exists()) {
                dir.mkdirs();
            }
            // 4. 保存文件
            File dest = new File(uploadDir + fileName);
            file.transferTo(dest);
            // 5. 返回访问URL
            return BaseResponse.success(accessUrl + fileName);
        } catch (Exception e) {
            e.printStackTrace();
            return BaseResponse.error("图片上传失败: " + e.getMessage());
        }
    }
}
```

```java
package com.campus.trade.controller;
```

```java
package com.campus.trade.base;

import java.lang.ref.WeakReference;

public abstract class BasePresenter<V extends BaseView> {
    protected WeakReference<V> mViewRef;  // 使用弱引用防止内存泄漏

    public void attachView(V view) {
        mViewRef = new WeakReference<>(view);
    }

    public void detachView() {
        if (mViewRef != null) {
            mViewRef.clear();
            mViewRef = null;
        }
    }

    protected V getView() {
        return mViewRef == null ? null : mViewRef.get();
    }

    protected boolean isViewAttached() {
        return getView() != null;
    }
}
```

```java
import retrofit2.Retrofit;
import retrofit2.converter.gson.GsonConverterFactory;

import java.util.concurrent.TimeUnit;

public class ApiClient {
    private static final String BASE_URL = "http://192.168.1.100:8080/"; // 替换为服务器IP
    private static Retrofit retrofit = null;
    private static ApiService apiService = null;

    public static ApiService getApiService() {

            synchronized (ApiClient.class) {
                if (apiService == null) {
                    // 日志拦截器
                    HttpLoggingInterceptor logging = new HttpLoggingInterceptor();
                    logging.setLevel(HttpLoggingInterceptor.Level.BODY);
                    
                    // OkHttp配置
                    OkHttpClient client = new OkHttpClient.Builder()
                            .addInterceptor(new AuthInterceptor())      // Token注入
                            .addInterceptor(logging)
                            .connectTimeout(30, TimeUnit.SECONDS)
                            .readTimeout(30, TimeUnit.SECONDS)
                            .writeTimeout(30, TimeUnit.SECONDS)
                            .build();

                    retrofit = new Retrofit.Builder()
                            .baseUrl(BASE_URL)
                            .client(client)
                            .addConverterFactory(GsonConverterFactory.create())
                            .build();
                    apiService = retrofit.create(ApiService.class);
                }
            }
        }
        return apiService;
    }
```

```java
package com.campus.trade.network.interceptor;

import com.campus.trade.utils.SharedPrefUtils;
import com.campus.trade.app.TradeApplication;
import okhttp3.Interceptor;
import okhttp3.Request;

import java.io.IOException;

public class AuthInterceptor implements Interceptor {
    @Override
    public Response intercept(Chain chain) throws IOException {
        Request original = chain.request();
        Request.Builder builder = original.newBuilder();
        
        String token = SharedPrefUtils.getToken(TradeApplication.getContext());
        if (!TextUtils.isEmpty(token)) {

        }
        return chain.proceed(builder.build());
    }
}
```

#### LoginPresenter.java
```java
package com.campus.trade.presenter.auth;

import android.content.Context;
import android.text.TextUtils;
import android.util.Patterns;
import com.campus.trade.model.repository.UserRepository;
import com.campus.trade.utils.SharedPrefUtils;

import java.util.HashMap;
import java.util.Map;

public class LoginPresenter implements LoginContract.Presenter {
    private LoginContract.View mView;
    private Context mContext;
    private UserRepository mRepository;

    public LoginPresenter(Context context) {
        this.mContext = context;
        this.mRepository = new UserRepository();
    }

    @Override
    public void attachView(LoginContract.View view) {
        this.mView = view;
    }

    @Override
    public void detachView() {
        this.mView = null;
    }

    @Override
    public void login(String email, String password) {
        // 校验邮箱
        if (TextUtils.isEmpty(email) || !Patterns.EMAIL_ADDRESS.matcher(email).matches()) {
            if (mView != null) mView.setEmailError("请输入有效的邮箱地址");
            return;
        }
        if (TextUtils.isEmpty(password) || password.length() < 6) {
            if (mView != null) mView.setPasswordError("密码不能少于6位");
            return;
        }

        if (mView != null) mView.showLoading();

        Map<String, Object> params = new HashMap<>();
        params.put("email", email);
        params.put("password", password);

        mRepository.login(params, new UserRepository.LoginCallback() {
            @Override
            public void onSuccess(String token) {
                if (mView != null) {
                    mView.hideLoading();
                    // 保存Token
                    SharedPrefUtils.saveToken(mContext, token);
                    SharedPrefUtils.saveUserEmail(mContext, email);
                    mView.onLoginSuccess();
                }
            }

            @Override
            public void onFailure(String msg) {
                if (mView != null) {
                    mView.hideLoading();
                    mView.showError(msg);
                }
            }
        });
    }

    @Override
    public void saveLoginInfo(String email, String password, boolean remember) {
        SharedPrefUtils.saveLoginInfo(mContext, email, password, remember);
    }

    @Override
    public String getSavedEmail() {
        return SharedPrefUtils.getSavedEmail(mContext);
    }

    @Override
    public String getSavedPassword() {
        return SharedPrefUtils.getSavedPassword(mContext);
    }

    @Override
    public boolean getRememberStatus() {
        return SharedPrefUtils.getRememberStatus(mContext);
    }
}
```

#### MessagePresenter.java（含轮询Handler逻辑）
```java
package com.campus.trade.presenter.message;

import android.os.Handler;
import android.os.Looper;
import com.campus.trade.model.entity.ChatMessage;
import com.campus.trade.model.repository.MessageRepository;

import java.util.List;

public class MessagePresenter implements MessageContract.Presenter {
    private MessageContract.View mView;
    private MessageRepository mRepository;
    private Handler mHandler = new Handler(Looper.getMainLooper());
    private Runnable mPollRunnable;
    private int mTargetUserId;
    private long mLastMessageId = 0;
    private boolean isPolling = false;
    private static final int POLL_INTERVAL = 3000; // 3秒

    public MessagePresenter() {
        this.mRepository = new MessageRepository();
    }

    @Override
    public void attachView(MessageContract.View view) {
        this.mView = view;
    }

    @Override
    public void detachView() {
        this.mView = null;
        stopPolling();
        mHandler.removeCallbacksAndMessages(null);
    }

    @Override
    public void startPolling(int targetUserId) {
        this.mTargetUserId = targetUserId;
        if (isPolling) return;
        isPolling = true;
        mLastMessageId = 0; // 可以从本地数据库读取最大ID优化
        doPoll();
    }

    private void doPoll() {
        if (!isPolling || mView == null) return;
        mRepository.pollMessages(mTargetUserId, mLastMessageId, new MessageRepository.MessageCallback() {
            @Override
            public void onSuccess(List<ChatMessage> messages) {
                if (mView != null && messages != null && !messages.isEmpty()) {
                    // 更新最后一条消息ID
                    mLastMessageId = messages.get(messages.size() - 1).getId();
                    mView.showNewMessages(messages);
                }
                scheduleNextPoll();
            }

            @Override
            public void onFailure(String msg) {
                // 轮询出错静默处理，继续下一次
                scheduleNextPoll();
            }
        });
    }

    private void scheduleNextPoll() {
        if (!isPolling) return;
        mHandler.postDelayed(this::doPoll, POLL_INTERVAL);
    }

    @Override
    public void stopPolling() {
        isPolling = false;
        mHandler.removeCallbacksAndMessages(null);
    }

    @Override
    public void sendMessage(String content, int targetUserId) {
        mRepository.sendMessage(content, targetUserId, new MessageRepository.MessageCallback() {
            @Override
            public void onSuccess(List<ChatMessage> data) {
                if (mView != null && data != null && !data.isEmpty()) {
                    mView.onSendSuccess(data.get(0));
                }
            }
            @Override
            public void onFailure(String msg) {
                if (mView != null) mView.showError("发送失败: " + msg);
            }
        });
    }

    @Override
    public void loadHistory(int targetUserId, int page) {
        mRepository.getHistory(targetUserId, page, 20, new MessageRepository.MessageCallback() {
            @Override
            public void onSuccess(List<ChatMessage> data) {
                if (mView != null) mView.showHistoryMessages(data);
            }
            @Override
            public void onFailure(String msg) {
                if (mView != null) mView.showError(msg);
            }
        });
    }

    @Override
    public void getUnreadCount() {
        mRepository.getUnreadCount(new MessageRepository.CountCallback() {
            @Override
            public void onSuccess(int count) {
                if (mView != null) mView.updateUnreadCount(count);
            }
            @Override
            public void onFailure(String msg) {
                // ignore
            }
        });
    }

    @Override
    public void markAsRead(int fromUserId) {
        mRepository.markAsRead(fromUserId, null);
    }
}
```

#### PublishPresenter.java（核心逻辑）
```java
package com.campus.trade.presenter.product;

import com.campus.trade.model.repository.ProductRepository;
import com.campus.trade.utils.ImageCompressUtil;
import java.io.File;
import java.util.ArrayList;
import java.util.List;

public class PublishPresenter implements PublishContract.Presenter {
    private PublishContract.View mView;
    private ProductRepository mRepository;
    private List<String> uploadedImageUrls = new ArrayList<>();

    public PublishPresenter() {
        this.mRepository = new ProductRepository();
    }

    // 上传单张图片（可并行调用）
    public void uploadImage(String filePath) {
        if (mView != null) mView.showLoading();
        File compressedFile = ImageCompressUtil.compressToFile(filePath, 1024 * 1024);
        mRepository.uploadImage(compressedFile, new ProductRepository.UploadCallback() {
            @Override
            public void onSuccess(String url) {
                uploadedImageUrls.add(url);
                if (mView != null) {
                    mView.hideLoading();
                    mView.onImageUploaded(url);
                }
            }
            @Override
            public void onFailure(String msg) {
                if (mView != null) {
                    mView.hideLoading();
                    mView.showError("图片上传失败: " + msg);
                }
            }
        });
    }

    // 提交商品信息
    public void publishProduct(String title, String description, String price, 
                               int categoryId, int condition) {
        if (uploadedImageUrls.isEmpty()) {
            if (mView != null) mView.showError("请至少上传一张图片");
            return;
        }
        if (mView != null) mView.showLoading();
        mRepository.publishProduct(title, description, price, categoryId, 
                condition, uploadedImageUrls, new ProductRepository.PublishCallback() {
            @Override
            public void onSuccess(Product product) {
                if (mView != null) {
                    mView.hideLoading();
                    mView.onPublishSuccess(product);
                }
            }
            @Override
            public void onFailure(String msg) {
                if (mView != null) {
                    mView.hideLoading();
                    mView.showError(msg);
                }
            }
        });
    }
}
```

#### ImageCompressUtil.java（压缩工具）
```java
package com.campus.trade.utils;

import android.graphics.Bitmap;
import android.graphics.BitmapFactory;
import java.io.ByteArrayOutputStream;
import java.io.File;
import java.io.FileOutputStream;
import java.io.IOException;

public class ImageCompressUtil {
    public static File compressToFile(String filePath, long maxSize) {
        File originalFile = new File(filePath);
        BitmapFactory.Options options = new BitmapFactory.Options();
        options.inJustDecodeBounds = true;
        BitmapFactory.decodeFile(filePath, options);
        
        int sampleSize = 1;
        while (options.outWidth / sampleSize > 1080 || options.outHeight / sampleSize > 1080) {
            sampleSize *= 2;
        }
        options.inSampleSize = sampleSize;
        options.inJustDecodeBounds = false;
        
        Bitmap bitmap = BitmapFactory.decodeFile(filePath, options);
        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        int quality = 90;
        bitmap.compress(Bitmap.CompressFormat.JPEG, quality, baos);
        
        while (baos.toByteArray().length > maxSize && quality > 20) {
            baos.reset();
            quality -= 10;
            bitmap.compress(Bitmap.CompressFormat.JPEG, quality, baos);
        }
        
        File compressedFile = new File(originalFile.getParent(), "compressed_" + originalFile.getName());
        try (FileOutputStream fos = new FileOutputStream(compressedFile)) {
            fos.write(baos.toByteArray());
        } catch (IOException e) {
            e.printStackTrace();
            return originalFile;
        }
        return compressedFile;
    }
}
```

### 4.9 SharedPrefUtils.java（本地存储工具）
```java
package com.campus.trade.utils;

import android.content.Context;
import android.content.SharedPreferences;

public class SharedPrefUtils {
    private static final String SP_NAME = "campus_trade_pref";
    private static final String KEY_TOKEN = "token";
    private static final String KEY_EMAIL = "email";
    private static final String KEY_PASSWORD = "password";
    private static final String KEY_REMEMBER = "remember";

    public static SharedPreferences getSP(Context context) {
        return context.getSharedPreferences(SP_NAME, Context.MODE_PRIVATE);
    }

    public static void saveToken(Context context, String token) {
        getSP(context).edit().putString(KEY_TOKEN, token).apply();
    }

    public static String getToken(Context context) {
        return getSP(context).getString(KEY_TOKEN, null);
    }

    public static void saveUserEmail(Context context, String email) {
        getSP(context).edit().putString(KEY_EMAIL, email).apply();
    }

    public static void saveLoginInfo(Context context, String email, String password, boolean remember) {
        getSP(context).edit()
                .putString(KEY_EMAIL, email)
                .putString(KEY_PASSWORD, password)
                .putBoolean(KEY_REMEMBER, remember)
                .apply();
    }

    public static String getSavedEmail(Context context) {
        return getSP(context).getString(KEY_EMAIL, "");
    }

    public static String getSavedPassword(Context context) {
        return getSP(context).getString(KEY_PASSWORD, "");
    }

    public static boolean getRememberStatus(Context context) {
        return getSP(context).getBoolean(KEY_REMEMBER, false);
    }

    public static void clear(Context context) {
        getSP(context).edit().clear().apply();
    }
}
```
